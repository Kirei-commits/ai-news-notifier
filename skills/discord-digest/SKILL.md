# Discord ダイジェストの書式

## 全体構成

```
**🤖 AI最新情報 (N件)**

**<情報源名>**
- [<日本語見出し>](<URL>)
- [<日本語見出し>](<URL>)

**<情報源名>**
- ...
```

## ルール

- 1 メッセージは 2000 文字まで。超える場合は件数を減らす（分割よりも精選を優先する）。
- 情報源ごとにまとめる。情報源の並びは「重要度の高い記事を含む順」。
- 1 情報源あたり最大 5 件。全体で 10 件を超えない。
- 見出しは日本語。ただし製品名・モデル名・企業名・技術用語は原語のまま
  （例: 「Gemini が long-context ツールに対応」）。
- 煽り表現・絵文字の多用はしない。見出し以外の感想や前置きを書かない。
- リンクは必ず元記事の URL。短縮や加工をしない。

## 除外するもの

- 既に通知済みの項目（`isNew` が false）
- 求人・イベント告知・製品広告のみの記事
- 同一ニュースの重複（複数ソースにまたがる場合は 1 件に統合し、代表的な 1 本にリンクする）
